# Pillar

Pillar è un gestionale web per imprese edili, pensato per gestire commesse, cantieri, preventivi, materiali e pagamenti con una dashboard utile in tempo reale.

## Funzioni principali

- Dashboard con KPI principali
- Gestione cantieri e commesse
- Elenco lavori e scadenze
- Monitoraggio materiali e fornitori
- Stato fatture e pagamenti
- Pianificazione risorse e turni

## Come avviare

```bash
git clone https://github.com/atore/pillar.git
cd pillar
python3 -m http.server 8000
```

Quindi apri il browser all'indirizzo:

```text
http://localhost:8000
```

## Struttura del progetto

- `index.html` - interfaccia principale
- `styles.css` - stile dell'applicazione
- `app.js` - logica e dati demo

## Tecnologie

- HTML5
- CSS3
- JavaScript vanilla

## Note

Questo è un prototipo iniziale, pronto per essere esteso con backend, autenticazione e database.
